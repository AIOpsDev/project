\synopsissection{PROBLEM}{%
Self-checkout and modern POS systems are established in international markets, yet access to comparable technology remains limited for smaller retailers in Bangladesh. High equipment costs and staffing constraints make conventional automation difficult to adopt. This creates a clear opportunity for an affordable, software-driven approach built around standard consumer hardware.
}

\synopsissection{PLATFORM}{%
The solution uses a modular POS engine that supports both cashier operations and customer self-checkout. A standard consumer laptop, webcam, and speakers provide the necessary hardware, keeping deployment adaptable and inexpensive.
}

\synopsissection{PIPELINE}{%
Items are scanned locally using OpenCV, with SQLite handling the primary product catalogue. A web search API resolves missing database records, and vision OCR extracts details directly from packaging. Before payment, an AI layer evaluates the cart to offer smart recommendations, such as suggesting cookies with coffee.
}

\synopsissection{LOCALIZATION}{%
For zero-latency operation, the system uses pre-recorded Bangla voice prompts. The checkout process concludes with a simulated Bangla QR payment interface, reflecting local mobile financial services.
}

\synopsissection{MARKET}{%
By eliminating specialized retail hardware, the system provides small and medium businesses a direct, low-cost path to digital sales automation.
}
